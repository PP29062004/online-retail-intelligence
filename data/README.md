# Source data

Download [Online Retail II](https://archive.ics.uci.edu/dataset/502/online+retail+ii) from the UCI Machine Learning Repository. Extract `online_retail_II.xlsx` into `data/raw`, then run `python src/pipeline.py` from the repository root. The five Power BI input tables and the cleaning audit appear in `data/processed`.

Daqing Chen, *Online Retail II*, [DOI 10.24432/C5CG6D](https://doi.org/10.24432/C5CG6D), [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).
